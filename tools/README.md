# Dev tooling

This directory holds dev-only tooling for the Checkpoint PWA. **The app itself ships zero npm runtime dependencies** — everything here is dev-time only.

## Tools

### `serve.mjs` — local HTTPS dev server

Service-worker registration and PWA install prompts require HTTPS (or `localhost`). Certs in `local-ssl/` are generated by [mkcert](https://github.com/FiloSottile/mkcert) and trusted by your local machine; they let you hit the app from your phone on the same Wi-Fi for real "Add to Home Screen" testing.

```powershell
npm run serve
# https://localhost:8443/
# also https://<lan-ip>:8443/ if the cert covers it
```

To regenerate certs (e.g., after a network change):

```powershell
cd tools\local-ssl
mkcert -cert-file localhost.pem -key-file localhost-key.pem localhost 127.0.0.1 ::1 <your-LAN-ip>
```

### `virtual-radio.mjs` — radio link simulator

A tiny WebSocket relay that lets two Checkpoint browser tabs exchange radio frames as if they were on a real radio link, no TNC or radio required. Optionally drops and delays messages to mimic an unreliable RF channel. See the file header for the full env-var knob list.

```powershell
npm run virtual-radio
# default: ws://localhost:8765/, lossless, no latency

$env:LOSS=0.1; $env:LATENCY_MS=500; npm run virtual-radio
# 10% loss, 500ms latency
```

The relay is transport-agnostic — whatever printable-ASCII line the app sends is what its peers receive. The Checkpoint app's Phase 1 Radio panel will get a small client shim to opt into this transport during development.

### `direwolf/` — software TNC (extracted)

Full Direwolf 1.8.1 binary release is unzipped here. Use it for actual AX.25 / APRS protocol testing, in either a real radio setup or a sound-card loopback.

Direwolf binary: `tools/direwolf/direwolf-1.8.1-a231971_x86_64/direwolf.exe`

See the [Direwolf User Guide](https://github.com/wb2osz/direwolf/blob/master/doc/User-Guide.pdf) and the bundled `direwolf.conf` for configuration.

### `local-ssl/` — mkcert-issued local certs

Gitignored. Regenerate per machine.

## npm scripts (run from repo root)

| Script | What it does |
|---|---|
| `npm run format` | Run prettier in write mode on `index.html`, `sw.js`, `manifest.json`, and tools. |
| `npm run format:check` | Same, but read-only — exits non-zero if formatting drifts. |
| `npm run lint` | Run eslint on `index.html` (via `eslint-plugin-html`), `sw.js`, and tools. |
| `npm run serve` | Start the local HTTPS dev server. |
| `npm run virtual-radio` | Start the radio link simulator. |

## Lighthouse

Installed globally. Run an audit:

```powershell
# while npm run serve is up:
lighthouse https://localhost:8443/ --view
```

The `--view` flag opens the HTML report in your default browser when the audit completes.
