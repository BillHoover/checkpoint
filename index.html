Google Sheets Setup

One-time setup (takes about 2 minutes):

  1. Open or create a Google Sheet.
  2. Menu → Extensions → Apps Script.
  3. Delete the default code, paste the script (see apps-script.js file with this app), save.
  4. Click Deploy → New deployment → gear icon → Web app.
  5. Set Execute as: Me, Who has access: Anyone. Click Deploy.
  6. Authorize when prompted.
  7. Copy the Web app URL and paste it into Settings.

Anyone with that URL can append rows to your sheet, so don't post it publicly. Each "Send to Google Sheet" appends a tab with the timestamp; nothing is overwritten.
